# dev-standard

项目开发与改造规范技能，适用于 ZCode 等支持 Agent Skills（`.agents/skills`）机制的 AI 编程工具。

## 核心原则

**先计划确认，再规范开发，最后测试交付。**

- **动手前**：出一份简短改造计划（改哪里、怎么改、分几步），不确定的点列为待确认项，绝不擅自决定
- **改造时**：规范优先，不在错误的结构上堆叠代码；风格跟随项目既有风格；改动公共方法必须检查所有调用方
- **编码**：消灭魔法数字；公共抽取恰当、不过度封装；关键位置有注释；入口和异常处有日志；会变化的值配置化
- **数据表**：加字段能复用的不加表；常查询字段考虑索引；不写循环逐条查库
- **性能与安全**：导出与批处理分批加流式写出防 OOM；参数化 SQL；数据修改考虑事务与幂等
- **交付**：测试文档 + 本地自测（缺环境如实说明缺什么）+ 测试报告

## 安装

复制 `SKILL.md` 到 AI 工具的用户级技能目录（如 ZCode 的 `~/.agents/skills/dev-standard/`），新会话生效。对 AI 说"开发 XX 功能""改造 XX 模块"即会触发。
